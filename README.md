### 🚀 Featured Project

#### 🛡️ [Distributed Rate Limiter & API Gateway](https://github.com/kalyaninemadework-pixel/-distributed-rate-limiter)
A FAANG-level production-ready rate limiter built from scratch.
- **Tech:** Go, Redis (Lua Scripting), Docker, Nginx.
- **Highlights:** Solves TOCTOU race conditions using atomic Redis Lua scripts. Handles concurrent traffic efficiently utilizing the Sliding Window Counter algorithm across multiple node instances.
